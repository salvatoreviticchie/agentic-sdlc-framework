# Tiny to-do app

A small command-line to-do list in Python (standard library only, Python 3.8 or later).

- Run it: `python3 todo.py add "Buy milk"`, `python3 todo.py list`, `python3 todo.py done 1`, `python3 todo.py clear-done`
- Test it: `python3 -m unittest -v` from this folder (or `python3 -m unittest discover -s app -v` from a project root where it sits in app/)
