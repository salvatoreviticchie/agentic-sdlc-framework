# Examples

- `tiny-app/`: a 90-line Python to-do list with 6 unit tests, for the 10-minute walkthrough in
  [docs/how-to.md](../docs/how-to.md). Copy it into the `app/` folder of an empty project, then run `/sdlc:init`.
  It has a planted weakness for the explorer to find; the hint is kept here, outside the app,
  so the explorer finds it from the code alone. (Spoiler: what does `todo.py done 0` do?)
